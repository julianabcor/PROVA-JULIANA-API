<h1> CONSUMO DE API </h1>
Desenvolvimento de uma aplicação para consumo de API meteorológica com Python e Streamlit

## Tecnologias necessárias:
- Python
- git
  
## Como rodar o repositório:
Primeiro clone e siga os passo do repositório da API:
- "git clone https://github.com/jpsvalentim/api-meteorologica-offline.git"

Após isso, clone esse repositório:
- "git clone https://github.com/julianabcor/PROVA-JULIANA-API.git"

## Bibliotecas utilizadas
Instale as bibliotecas "requests" e "streamlit"
- "pip install requests"
- "pip install streamlit"
- "pip install -r requirements.txt
